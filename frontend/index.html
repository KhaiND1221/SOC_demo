SOC Logging Lab

Minimal web app with full logging across Nginx, FastAPI (app + auth loggers), and PostgreSQL, built for SOC Tier 3 log-correlation training. See the project README.md and LOGGING_MAP.md for the endpoint-to-log mapping and the 10 walkthrough scenarios.

Scenario: application exception (500)

Calls GET /api/debug/crash. The response only shows a generic message + request_id; the full stack trace is written server-side only (app.log, event="unhandled_exception"). Use the request_id below to grep the log.
